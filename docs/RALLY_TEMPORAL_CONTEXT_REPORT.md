with a prospective owning-issue seal, genuine grant, original-host provenance
and real shared Store admission. The frozen metadata gate verifies all 1,014
historical execution identities and 256 validated targeted references without
opening old scientific labels. Original failures, clocks, fences and deadlines
remain unchanged. The owner delegated this frozen-scope decision while away;
no personal human PR review is asserted.

The pilot permits six fresh existing ChatGPT-authenticated Codex CLI sessions:
two independent readings and a separate blind source adjudication per source.
Each receives its complete chronological sparse gallery, native metadata and
fixed rubric, with no other stream's labels, predictions or model outputs.
Only coarse scene/play state and local visual actor continuity are assessed.
Actor IDs remain local to each stream. A shared string or court position does
not establish a person, and repeated sampled observations do not establish
continuous tracking between them.

The four-hour interval starts at the new grant and renews no earlier scientific
runtime. Limits are 9 MiB / 20 gallery images per session, a 14 MiB local encoded
guard, 128 MiB new attempted payload, 512 MiB new retained outputs and 8 GiB
cumulative payload/output ceilings. Every failed attempt is charged; any failure
stops dispatch with no replacement or implicit retry. Galleries, original labels
and execution receipts remain private. All six genuine execution identities and
process exits must verify before scientific comparison.
