# Complete-rally source reference pilot

The prospective two-source development pilot for issue #62 is being prepared.
No complete reference or improvement in automatic annotation accuracy has yet
been established. Both source slots remain in the denominator. Tasks #66, #67
and #71 remain blocked on their actual reference prerequisites.

The [public protocol](../data/manifests/rally_reference_protocol_v1.json) freezes
the two previously prepared BWF originals, original native clocks, deterministic
five-second overview and earliest warranted provisional rally selection.
Sparse screening cannot establish exhaustive contacts or complete rallies.
Native dense assessment requires every selected frame, two independent source
streams and separate fresh source adjudication, with unknowns preserved.

The source-only producer uses the original shared Store. Original display PNGs,
private labels, actual session/coverage receipts and process evidence stay
ignored. No models, predictions, application annotations or weights are used.
All training, independent-test, deployment and redistribution flags stay false.
Agreement between agents is not expert certification.

The task has a four-hour deadline from its original grant, a 4 GiB persisted
output ceiling and a 2 GiB cumulative image-transfer ceiling. Each fresh session
may receive at most 20 native PNGs and 6 MiB, including any repeated context.
Impossible coverage within these bounds leaves an incomplete source slot;
images must not be resized or omitted to manufacture completeness.

Execution, software verification and actual source outcomes will be recorded
here separately. No real source assessment has started at this protocol commit.
